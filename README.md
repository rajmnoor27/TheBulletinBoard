# TheBulletinBoard

TheBulletinBoard is a dynamic web application engineered to aggregate and display news articles from multiple sources. Designed for users seeking a streamlined way to access and interact with real-time news, this project integrates powerful tools and planned enhancements to enrich the user experience.

## Features

### Current Functionality
- **News Aggregation**: Fetches and displays news articles from various sources using integrated APIs (e.g., New York Times API).
- **Keyword Search**: Enables users to search for articles using specific keywords.
- **Email Sharing**: Provides a feature for users to share articles via email directly from the platform.

### Planned Enhancements
- **User Authentication**: Secure user accounts with login and registration functionality.
- **Real-Time Fact-Checking**: Implement tools to verify the credibility of news articles.
- **Advanced Technologies**:
  - **Backend Integration**: Utilize Node.js for server-side operations.
  - **Modern Frontend Framework**: Transition to React.js for an enhanced user interface.
  - **Cloud Services**: Incorporate Google Firebase for seamless data storage and user management.

## Technologies Used
- **Frontend Development**: HTML, CSS, JavaScript
- **APIs**: New York Times API, Bing News Search API, NewsAPI

## Getting Started

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/TheBulletinBoard.git
   ```
2. Navigate to the project directory:
   ```bash
   cd TheBulletinBoard
   ```
3. Obtain API keys for the following services:
   - [New York Times API](https://developer.nytimes.com/)
   - [Bing News Search API](https://www.microsoft.com/en-us/bing/apis/bing-news-search-api)
   - [NewsAPI](https://newsapi.org/)
4. Add the API keys to the project's script.js file as instructed in the documentation.
5. Open the `index.html` file using a live server to view the application locally.

### Usage
- Use the search bar to find articles based on specific keywords.
- Click the Read More Button to access articles directly.
- Click the Share Button to share articles directly.
